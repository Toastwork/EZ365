Mise en place — une seule fois

{% if portal %}
Acces direct (connecte sur le tenant qui heberge EZ365) : Inscription de l'application Certificats & secrets Autorisations de l'API

Introuvable dans « Inscriptions d'applications » ? Ouvrez l'onglet « Toutes les applications » (et non « Applications detenues »), verifiez le repertoire actif en haut a droite, puis cherchez l'ID client {{ portal.Overview.rsplit('/', 1)[-1] }}. Si elle n'apparait que dans « Applications d'entreprise », l'inscription appartient a un autre tenant : creez la votre (multilocataire) puis remplacez MS_CLIENT_ID et MS_CLIENT_SECRET dans la stack.

{% endif %}
  1. Deposer le certificat sur l'application Azure. Portail Azure → Microsoft Entra ID → Inscriptions d'applications → EZ365 → Certificats & secrets → onglet Certificats → Charger un certificat → le fichier .cer ci-dessus. L'empreinte affichee par Azure doit correspondre a celle de cette page.
  2. Ajouter la permission SharePoint. Meme application → Autorisations de l'API → Ajouter une autorisation → SharePoint → Autorisations de l'application → Sites.FullControl.All.
  3. Verifier les permissions Graph. Meme ecran → Microsoft Graph → Autorisations de l'application :
    PermissionPour
    User.ReadWrite.Allcreer les comptes, attribuer les licences
    Organization.Read.Alllicences disponibles (lecture seule)
    Domain.Read.Alldomaines du client (lecture seule)
    Group.Createcreer le groupe d'un site d'equipe
    GroupMember.ReadWrite.Allajouter les utilisateurs aux sites
    Sites.ReadWrite.Alldossiers, OneDrive et raccourcis
    Group.ReadWrite.All et Files.ReadWrite.All ne sont pas necessaires ; ajoutez la seconde seulement si un raccourci echoue en 403.
  4. Faire accepter la permission par les clients deja connectes. Bouton « Renouveler » du tableau ci-dessus, avec un compte administrateur du client. Les nouveaux clients l'acceptent d'office en se connectant.

Tant que ces etapes ne sont pas faites, le journal d'un provisionnement indique « Demande de creation des OneDrive refusee » avec la raison exacte, et les OneDrive des comptes jamais connectes ne sont pas crees.
